## What is TradeTalk?

TradeTalk is a **Vite-based social trading mini-app** designed for real builders and alpha sharers on Base.  

Users connect their wallet, see live prices, share trading alpha, and tip each other directly. It combines **social features + AI agents + onchain monetization** in one lightweight mobile-optimized interface.

Built as a nights-and-weekends project by a solo builder grinding with small capital, TradeTalk proves that meaningful onchain experiences can be shipped fast and used immediately.

**Core mission:** Make trading social, transparent, and rewarding on Base — helping more people come onchain through community alpha and tips.

---

## Why Base?

- Super low gas → perfect for frequent social interactions and small tips
- Growing creator & DeFi community
- Fast iteration with OnchainKit + MCP AI agents
- Aligned with real user behavior (mobile-first, quick alpha sharing)

TradeTalk is fully deployed and functional on Base mainnet.

---

## Key Features

- 🔗 **Wallet Connect** (wagmi) — instant connection, no friction
- 📈 **Live Prices** — real-time market data
- 🤖 **MCP AI Agents** — intelligent alpha assistance and insights
- 💬 **Share Alpha** — post and discover trading ideas in a social feed
- 💰 **Tips Mechanic** — direct onchain tips to alpha sharers
- 📱 **Mobile-First Design** — Bloomberg-terminal dark UI, built for phone trading
- ⚡ **Fast & Lightweight** — Vite + Vercel deployment

---

## Tech Stack

- **Frontend:** Vite, React, Tailwind CSS
- **Wallet & Onchain:** wagmi, OnchainKit (planned expansion)
- **AI Agents:** MCP Protocol
- **Data:** CoinGecko (prices), Supabase (chat/alpha storage — migrating onchain)
- **Deployment:** Vercel
- **Chain:** Base (mainnet)
